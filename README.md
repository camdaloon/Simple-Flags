# Simple Flags

Simple Flags is a Paper plugin by camdaloon that adds simple flags to Minecraft.

## Version

v1.0.0-0_alpha

## Alpha Features

- Craftable blank flags
- Transferable flag items
- Creator and flag name identity
- Persistent flag artwork
- Inventory canvas
- Four dye input slots
- Live mixed-color preview
- Brush sizes
- Freehand painting
- Erasing
- Flag copying with a blank flag
- `/version SimpleFlags`
- `/simpleflags reload`
